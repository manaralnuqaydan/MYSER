## ضوابط عرض المحتوى

- الروابط أعلاه تُفتح خارج MYSER؛ لا تُرسل بيانات النموذج إلى الجهات.
- «آخر تحقق» يعني تاريخ مراجعة المصدر الرسمي، وليس ضمان استمرار المسار أو شروطه.
- أهلية التسجيل والرخص والموافقات تعتمد على النشاط والشكل القانوني والموقع والظروف الفردية. يجب مراجعة المصدر الرسمي قبل اتخاذ إجراء.
- المساعد والطلبات والمحفظة واجهات محلية تجريبية. لا توجد مصادقة نفاذ أو API أو تكامل حكومي.
- صفحات بعض الجهات قد تمنع أدوات الفحص أو تعيد توجيهها؛ وُسمت الحالة بوضوح بدل ادعاء اختبارها مباشرة.
